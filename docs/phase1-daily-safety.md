# 第一阶段：日常使用保障（仅 Preview）

基线：main 18b2fb3。禁止自动合并 main。正式数据库不做测试写入。

## 范围
- 本地未保存收藏草稿：新建/编辑隔离，账号+空间隔离；包括照片及排序；恢复前询问；成功保存后清除。
- 中断重试保留保存会话，避免重复创建实例；本地存储失败明确提示。
- 详情备注、按当前实例读取移动记录（时间/状态/位置/操作人）。
- 已删除位置恢复；上级已删除时先恢复上级，不自动改变原层级。
- 收藏浏览模式、搜索和位置筛选记忆，以及返回分页/滚动位置。

## 边界
- 草稿不是云端备份：清除浏览器数据会丢失，不跨设备同步。
- 不增加忘记密码/重发邮件，不增加双人冲突处理，不做批量操作。
- 位置恢复不对收藏、图片或编号做删除/重排。
- 每项先本地隔离测试，再 Preview 验证，最终由用户决定是否合并。

## 本地验证（2026-09-06）
- lint、TypeScript 生产构建、22 个单元/隔离 API 测试通过。
- 390/1280 浏览器：照片草稿取消/刷新恢复、保存成功清除、上传失败刷新重试不重复入库。
- 备注显示、按实例历史分页、位置恢复、列表与分页记忆回归。
- 原照片专项及完整冒烟回归通过，历史图片 hash 不变。
- 所有浏览器测试仅访问 localhost，真实 gucang/test 无测试写入。
- Preview 构建必须连接 gucang-test，否则拒绝构建；Production 环境不受此检查影响。

## 已知边界
- 浏览偏好目前为同一浏览器标签页会话记忆；新标签页不保证继承。
- 本阶段草稿覆盖收藏新建/编辑，位置表单暂不提供草稿。
- 浏览器被系统强制杀死时，尚未完成的本地写入不能保证保留；本地存储不是备份。
- 尚未在真实小米设备验证，Preview 仍需用户试用。
