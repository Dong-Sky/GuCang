# 5B 到期回收站维护 Preview

- 基于5A开发，现与5C统一进入 `feat/phase5-performance` Preview；main未修改。
- 移除启动时的隐式删除。设置中管理员确认后按批清理超过7天的实例，每批最多20款。
- 数据库事务同时保留图片删除任务和删除到期记录。图片请求失败不丢失路径，任务记录失败原因、尝试次数，并可在下次访问重试。
- 同款仍有持有实例时保留款式与照片；剩余图片记录仍引用的路径不加入删除任务。
- 权限由数据库管理员成员检查和RLS共同约束；全部函数为security invoker，无服务端特权密钥。
- 无定时任务；不会扫描或删除未关联文件、历史原图、编辑删除的旧图。当前批只负责到期收藏。清理后刷新页面更新计数。
- 维护任务/日志不属于浏览器版本2业务备份内容；待清理路径对应已经到期移除的记录，而非仍持有收藏。
