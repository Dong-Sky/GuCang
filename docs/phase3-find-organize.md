# 第三阶段：查找与资料整理（仅 Preview）

基线 main 54c250d；分支 feat/phase3-find-organize。禁止自动合并 main。

## 功能与试用顺序
1. 收藏展开「筛选与排序」：组合 IP、品类、角色、系列、状态，与原搜索、位置、资料缺失筛选叠加；可重置。支持最近/最早入库、最近修改。偏好按账号/家庭会话保留。
2. 添加/编辑：选择 IP 后从已有角色列表逐个追加；每行一个名字，支持多角色与新名字。空格不会拆开历史名字。更换 IP 清空角色/系列，避免串作品。系列建议只显示当前 IP；照片和连续入库逻辑不变。
3. 设置底部「资料整理」：选择 IP/角色/品类/系列，改名与维护别名，或者选择保留的目标进行合并。必须先预览，再确认；更改输入会取消旧确认。
4. 合并仅调整资料关联，原分类软删除，旧名成为目标别名。包含回收站内的款式/实例，数量明确显示。IP 合并同时搬迁角色/系列，不擅自去重同名子资料；角色/系列必须同 IP 才能合并。
5. 首页与收藏搜索可命中别名和 IP 多语言名字；编号搜索仍精确定位实例。
