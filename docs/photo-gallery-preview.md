# 多图 Preview

本分支只更新照片交互，不包含数据库迁移。历史图片文件及记录保持原样。

- 每件收藏的展示模型保留全部未删除照片，依照 sort_order、created_at、id 排序；列表继续使用第一张。
- 新选照片三列完整展示，44px 移除入口；允许移除后重新添加，首张自动作为主图。
- 选择时检查可读性、按文件内容识别重复、提示超过三张的选择；检查期间禁用保存。
- 详情提供缩略图、前后切换、照片区域滑动和完整图片查看；32px 左边缘不触发相册切换。
- 编辑可查看全部已保存照片。已保存照片的删除、替换、重新排序未在本次开放，防止误删历史图片。
- 部分上传成功后的重试保留原有幂等流程，并解释照片暂时锁定的原因。

## 验证

按照 performance-optimization.md 启动连接本地模拟 API 的构建后，运行 tests/photo-browser.mjs。
此脚本覆盖 390px 手机与 1280px 桌面下的三张选择、移除补选、重复文件、无效文件、超额提示、保存、详情切换、滑动、边缘排除、放大关闭与编辑旧图。
tests/browser-smoke.mjs 覆盖压缩、弱网重试、历史照片保留、搜索和收藏操作。

本地测试构建含模拟 URL，不可直接发布预构建产物；Preview 由 GitHub 推送触发 Vercel 重新构建。
# 新选照片排序

新选照片支持底部手柄拖动排序，以及左右按钮逐位移动。第一张为主图；已有照片不参与排序。上传重试锁定期间禁止排序，避免已上传照片与重试顺序错配。

390px / 1280px 浏览器测试覆盖鼠标拖动、触摸拖动、箭头移动，并读取本地模拟存储的图片像素，确认 sort_order 对应排序后的绿、红、蓝顺序。未向正式数据库写入测试数据。
